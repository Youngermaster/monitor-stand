\section{Heat-set inserts}\label{sec:inserts}

Install all 12 inserts \textbf{before} painting and before any assembly. Each part keeps its inserts; the feet and the
VESA plate have none (they only have clearance holes).

\begin{step}{How to set an insert}
\begin{enumerate}
  \item Lay the part so the hole points straight up (for the base side holes, put the base on its side on a towel).
  \item Place the insert on the hole, small end down. Heat it with the iron at 220--230\,°C and let it sink under its own
        weight with light pressure. Do not push hard: the plastic must melt, not crack.
  \item Stop when the insert is about 0.5\,mm proud, remove the iron and press it \textbf{flush} with the flat block.
        Hold it 5--10\,s so it cools straight.
  \item Check with a screw that the thread is square. Clean any plastic squeezed into the thread with the screw.
\end{enumerate}
\end{step}
